# 🎨 One-Page Portfolio with Tailwind CSS

A simple, responsive one-page portfolio built using Tailwind CSS via CDN. This project is designed as a beginner-friendly assignment to practice layout, image handling, modern utility-first styling, and implementing a light and dark mode toggle feature.

## 🚀 Live Demo

🔗 [View Portfolio Live](https://leafy-bunny-17cb95.netlify.app/)

---

## 📸 Features

- Fully responsive layout using Tailwind CSS
- Profile picture displayed at the top
- Short biography section with name, current learning path, and hobbies
- Vertically and horizontally centered content
- Styled text and background for a clean modern look
- **Light and Dark Mode** toggle feature for better user experience

---

## 🛠️ Technologies Used

- **HTML5** – semantic markup
- **Tailwind CSS** – utility-first styling (via CDN)
- **Netlify**  – for hosting and deployment
- **JavaScript** – for toggling between light and dark mode
